# VideoGames

Aprendiendo a hacer videojuegos 2D mediante Lua y Love, siguiendo tutoriales de CS50

## Etiquetas de Commits

FEAT: nuevas funcionalidades o características

FIX: corregir errores para el usuario

DOCS: añadir documentación

CHORE: mantenimiento del sistema (borrar, reorganizar y limpieza)

STYLE: cambios de formato

REVERT: revertir un commit anterior
